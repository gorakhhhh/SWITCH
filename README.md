## Cisco Switch Practical Guide – CCNA Networking

This PDF contains hands-on Cisco switch configuration practicals designed for CCNA students, networking beginners, and IT professionals.

- Basic switch configuration
- Hostname and password configuration
- Console and enable password security
- VLAN creation and configuration
- Assigning switch ports to VLANs
- Trunk port configuration
- Inter-VLAN communication basics
- Switch port security
- Verification commands and troubleshooting
- Practical CLI commands with examples

### Learning Objectives
Understand how to configure, secure, and troubleshoot Cisco switches using practical lab exercises.
